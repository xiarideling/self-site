我试用过的 Agent

不是榜单，是使用记录。判断标准只有一条：它有没有真的减少我动手的时间。 演示好看但需要反复纠正的，最后都进了「弃用」。

共 0 个 · 状态里「常用」是还在日常用，「在试」是刚上手，「弃用」是已经停了。

我怎么判断一个 Agent 值不值得留下

看返工率
纠正它的时间 < 自己做的时间这条不过，其他优点都不算数
看边界
它知不知道自己不会会编造的，比会拒绝的难用得多
看复利
用得越久是否越省事能记住项目和习惯的，才值得长期留
别往下翻了，你已经发现了最底下的我了哦~
